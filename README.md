
# Developer Portfolio

A responsive personal software developer portfolio built
with HTML, CSS, and JavaScript.

## Overview

This website presents my education, technical skills,
development interests, and personal projects.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Website Sections

- Responsive Navigation
- Hero
- About Me
- Technical Skills
- Featured Projects
- Education
- Contact
- Footer

## Features

- Responsive layout
- Mobile navigation
- Reusable project cards
- Accessible semantic HTML
- Keyboard navigation
- Reduced-motion support
- Contact profile links when configured

## Project Structure

- `index.html` - Main page
- `css/style.css` - Website styles
- `js/main.js` - Main interactions
- `js/projects.js` - Project data
- `js/contact.js` - Public contact data
- `assets/` - Images, icons, and resume

## Running Locally

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Open `index.html` with Live Server.
